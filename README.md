# MyGameList

MyGameList es una aplicación web para la gestión y seguimiento de bibliotecas personales de videojuegos, inspirada en MyAnimeList. Permite a los usuarios llevar un registro detallado de los juegos que están jugando, han completado, planean jugar o han abandonado[cite: 2].

## Estructura del Proyecto

El proyecto está dividido en dos partes principales: el backend y el frontend.

```text
├── BACKEND
│   ├── controllers
│   ├── database
│   ├── models
│   ├── node_modules
│   ├── routes
│   ├── package-lock.json
│   ├── package.json
│   └── server.js
└── FRONTEND
    ├── assets
    ├── controllers
    ├── views
    └── package-lock.json[cite: 1]

```

## Características

* **Gestión de usuarios:** Registro, inicio de sesión, personalización de perfil y estadísticas personales.

* **Biblioteca personal:** Clasificación de juegos por estado, registro de tiempo de juego y plataforma, y lista de favoritos.

* **Catálogo de juegos:** Búsqueda, filtros por género y plataforma, e información detallada de cada título.

* **Personalización:** Creación de géneros personalizados y asignación de colores a las plataformas.

## Tecnologías

* **Backend:** Node.js
* **Frontend:** JavaScript, HTML, Bootstrap
* **Base de datos:** MongoDB
